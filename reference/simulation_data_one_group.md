# Simulation Data for One Group

Simulated p-values and metadata for a two group comparison. Useful for
Type I error calculations.

## Usage

``` r
simulation_data_one_group
```

## Format

\## \`simulation_data_one_group\` A list

- p_values:

  A data frame of p-values from each run of each test

- initial_groups:

  A nested list with information for each simulation run
