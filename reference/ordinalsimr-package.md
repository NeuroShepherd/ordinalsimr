# ordinalsimr: Compare Ordinal Endpoints Using Simulations

Simultaneously evaluate multiple ordinal outcome measures. Applied data
analysts in particular are faced with uncertainty in choosing
appropriate statistical tests for ordinal data. The included 'shiny'
application allows users to simulate outcomes given different ordinal
data distributions.
